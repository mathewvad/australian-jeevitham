Syntax

* every value
5 one value
1,15 a list
9-17 a range
*/15 every 15th
0-30/5 every 5th in a range
MON-FRI day names
JAN,JUL month names
@daily same as 0 0 * * *
@hourly same as 0 * * * *

This reads the standard 5-field cron used by Linux crontab. Day of week runs 0 to 6 with Sunday as 0 (7 also means Sunday). When both day of month and day of week are set, the job runs when either one matches.
