About hash functions

A hash function turns any text or file into a short, fixed-length "fingerprint". The same input always gives the same hash, and even a one-letter change gives a completely different one. You cannot turn a hash back into the original data. A SHA-256 hash, for example, is always 64 hex characters long, whatever the size of the file.

How do I check a download?

Many software sites publish a SHA-256 checksum next to the download. Open the downloaded file here, and paste the published checksum into the "Compare with a checksum" box. If they match, the file has not been changed or damaged.

What is HMAC?

HMAC mixes a secret key into the hash. Only someone with the same key can make the same HMAC, so it is used to prove that a message - such as a webhook from an online service - really came from the right sender and was not changed.

Can I store passwords as SHA-256 hashes?

No. Fast hashes like SHA-256 and MD5 can be guessed billions of times a second. Passwords need a slow password-hashing method such as Argon2, scrypt or bcrypt - see the OWASP password storage guide.
