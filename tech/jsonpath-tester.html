JSONPath Tester

Try a JSONPath expression against your JSON and see every matching value and where it sits in the document.

JSONPath expression

Type a path that starts with $.
JSON input
Matches 

      

    

    

      
      
    

    

      
Syntax

      

        
$ the whole document

        
.name a child by key

        
['a b'] a key with spaces

        
[0] an array item

        
[-1] the last item

        
[*] every child

        
..name search at any depth

        
[0:2] a slice (start:end:step)

        
[0,2] several items

        
[?(@.a > 1)] a filter

        
&& || ! combine filters

        
[?(@.a)] key exists
