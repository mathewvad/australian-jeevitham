JSON ⇄ CSV / YAML

Convert between JSON, CSV and YAML in either direction. Nested objects become dotted column names in CSV. Nothing leaves your browser.

Paste some data, then press Convert (or just start typing).

JSON to CSV works best with a list of objects, like [{"name":"A","age":30}, ...]. Each object becomes a row; nested objects become columns such as address.city, and lists are kept as JSON text in one cell.
