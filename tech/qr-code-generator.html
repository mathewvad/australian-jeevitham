About QR codes

A QR code stores text - most often a web link - as a pattern of black and white squares that a phone camera can read. The text is inside the picture itself, so a QR code made here never expires and does not track who scans it.

Which error correction level should I choose?

Error correction lets a scanner read the code even when part of it is dirty, torn or covered. Higher levels survive more damage but make the code denser:

  • Low (7%) - for screens and clean prints where the code stays undamaged.
  • Medium (15%) - a good choice for most printing.
  • Quartile (25%) or High (30%) - for posters outdoors, stickers that may wear, or when you place a small logo over the middle.

Tips for codes that scan every time

  • Keep the link short - shorter text makes a simpler code that scans from further away.
  • Keep the quiet zone (the empty border). Four modules is the usual size.
  • Use a dark colour for the squares on a light background, with strong contrast.
  • Choose SVG for printing, because it stays sharp at any size.
  • Test the printed code with two or three different phones before you print many copies.
