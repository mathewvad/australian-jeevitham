About URL encoding

A web address can only contain a limited set of characters. Others - spaces, &, ?, # and non-English letters such as Malayalam - must be "percent-encoded": each byte becomes % followed by two hex digits. A space becomes %20, & becomes %26, and the Malayalam letter അ becomes %E0%B4%85. The rules are in RFC 3986.

Which mode should I use?

  • Component - for one value inside a URL, such as a search word. It also encodes &, / and ?.
  • Full URL - for a whole address. It keeps : / ? & so the link still works.
  • Form - like Component, but spaces become +, the way web forms send data.

Why does my link break?

Usually a value contains & or # that was not encoded, so the browser reads the rest as a new parameter or as a page section. Encode each value in Component mode before you join them into the address.

What is the URL parser for?

Paste any long link - for example one with tracking codes - to see its parts and every query parameter in a table, already decoded. It is a quick way to check what a link really contains before you click or share it.

Encoding, decoding and parsing all happen in your browser, and nothing is uploaded.
