About UUIDs and random passwords

A UUID (universally unique identifier) is a 128-bit ID written as 36 characters, such as 3f2b8c1e-9d4a-4c7b-a1e2-5b6f7a8c9d0e. The version 4 UUIDs made here are random - 122 of the 128 bits are random - so the chance of two ever being the same is tiny. Developers use them for database keys, file names and request IDs. UUIDs are defined in RFC 9562.

Version 4 or version 7?

A version 7 UUID starts with a timestamp, so new IDs sort in the order they were made, which can help database indexes. Version 4, which this page makes, is fully random and reveals nothing about when it was created.

How strong are the passwords?

Every character is picked by your browser's secure random number generator, so the passwords cannot be predicted. Length matters most: each extra character multiplies the number of possible passwords, so a longer password is always stronger.

Password or passphrase?

A passphrase of random words is easier to remember and type. The Australian Cyber Security Centre recommends a passphrase of at least four random words and 15 characters, and a different one for every account. Store your passwords in a password manager, and turn on multi-factor authentication wherever you can.
