Naming styles in code

Programmers join words without spaces in a few standard ways. Each language and tool has its own habits:

StyleUsually used for
camelCase
firstName		Variables and functions in JavaScript and Java
PascalCase
UserProfile		Classes, React components, C# names
snake_case
first_name		Python variables and database columns
kebab-case
main-header		CSS classes, web addresses and file names
CONSTANT_CASE
API_KEY		Constants and environment variables
dot.case
app.name		Keys in settings and properties files

Whatever style you choose, use the same one all through a project.

Title Case or Sentence case?

Title Case capitalises most words; Sentence case capitalises only the first word and names. Sentence case is easier to read, and the Australian Government Style Manual uses it for headings.

Handy uses for the line tools

  • Remove duplicate email addresses or names before a mail merge.
  • Sort a list of names, suburbs or products A to Z.
  • Remove empty lines and extra spaces from text copied out of a PDF or email.
