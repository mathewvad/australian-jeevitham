About JSON Web Tokens

      
A JSON Web Token (JWT), defined in RFC 7519, is a compact way to pass facts - such as who a user is and when their login ends - between systems. It has three parts separated by dots: the header, the payload and the signature. The header and payload are just URL-safe Base64 JSON, so anyone can read them. The signature proves they have not been changed.

The times are Unix timestamps in seconds. You can check one with the timestamp converter.

      
HS256 or RS256?

      
HS256 signs and checks the token with one shared secret. RS256 signs with a private key and checks with a public key, so other services can verify tokens without being able to create them. This page can check HS256 signatures.

      
Is it safe to decode a token here?

      
Decoding happens in your browser and the token is not sent anywhere. But while a token is valid it works like a password, so avoid pasting live production tokens into any website, and never put secrets in a JWT payload - it is not encrypted.
