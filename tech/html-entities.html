About HTML entities

In HTML, < starts a tag and & starts an entity. To show these characters as text, you write them as entities: &lt; for <, &gt; for >, &amp; for &, &quot; for " and &#39; for '.

An entity can be a name, a decimal number or a hex number. &mdash;, &#8212; and &#x2014; all show the same long dash: —.

Why does escaping matter for security?

If a website shows text that people type without escaping it, someone can slip in a <script> and run their own code on your page. This is called cross-site scripting (XSS). Escaping & < > " ' before putting text into HTML stops it. See the OWASP guide to preventing XSS.

Do I need entities for Malayalam text?

No. If your page is saved as UTF-8 and has <meta charset="UTF-8">, you can type Malayalam, Hindi or Tamil letters straight into the HTML. Entities are only needed for the special characters above.
