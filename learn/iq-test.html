IQ test for fun

Pattern puzzles, number series, odd one out and logic - 24 questions against the clock, with a score for each part at the end.

How the test works

  • 24 questions in 12 minutes.
  • The questions are made fresh every time, so you can take the test again.
  • You cannot go back, so answer or skip each question and move on.
  • Your answers are marked on your own device. Nothing is saved or sent.

What an IQ test measures

IQ stands for intelligence quotient. A real IQ test is a standardised test given by a trained psychologist, and its scores are set so that the average person scores 100. About two in every three people score between 85 and 115.

This page is an IQ-style puzzle test for fun, so its result is only a rough guide. It uses four kinds of question:

  • Pattern puzzles - find the shape that comes next.
  • Number series - find the next number in the list.
  • Odd one out - spot the item that does not belong.
  • Logic - work out what must be true from a few facts.

Can I improve my score?

On puzzle tests like this, yes. The more you practise, the more familiar the question types become, so scores usually go up. That is one reason a score from a puzzle test is not a true measure of IQ.

Is this the same as a job aptitude test?

Not quite. Many job aptitude tests use similar pattern and number questions, but they also test reading and working with data, and you are compared with other job applicants. To get ready for one, try our aptitude test practice.
